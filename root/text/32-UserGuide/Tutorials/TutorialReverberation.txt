\page TutorialReverberation X-ray reverberation mapping of an AGN geometry

This tutorial introduces the time lag tracking capabilities of the SKIRT code (see \ref UserTimeLags). You will examine
X-ray reverberation mapping, a technique used to estimate the time lag between direct and reprocessed emission in an
active galactic nucleus (AGN). In this model, the AGN is represented by cold gas in a parsec-scale torus surrounding a
central source. You will create a ski file containing the appropriate simulation parameters, perform the SKIRT
simulation, and analyze the results, focusing on the time lag and X-ray spectra in the 2 to 12 keV range.

\section TutorialReverberationPre Getting ready

This tutorial assumes that you have completed the introductory SKIRT tutorial \ref TutorialXRayTorus and that you have
reviewed the topic \ref UserTimeLags, or that you have otherwise acquired the working knowledge introduced there. At
the very least, before starting this tutorial, you should have installed the SKIRT code.

\subsection TutorialReverberationGrid Spatial grid

\verbatim

\endverbatim

This value specifies the number of random locations sampled within each spatial cell to estimate its total mass. A
higher value improves the accuracy of the mass distribution, especially in regions with steep density gradients, but
increases the initial setup time. For this tutorial, specify the default value.

\verbatim
   Possible choices for the spatial grid:
      1. A 2D axisymmetric spatial grid in spherical coordinates
      2. A 2D axisymmetric spatial grid in cylindrical coordinates
      3. A 3D spatial grid in spherical coordinates
         ...

 ? Enter the inner radius of the grid [0 pc,∞ pc[ (0 pc): 2.4e-2 pc
 ? Enter the outer radius of the grid ]0 pc,∞ pc[: 4.8e-2 pc
\endverbatim

SKIRT discretizes the medium on a spatial grid, i.e. a collection of small cells in which properties such as medium
density are considered to be uniform. For this model, choose a 2D axisymmetric grid in spherical coordinates to take
advantage of the model's symmetry. This significantly reduces computational costs while maintaining high resolution.

Configure the inner and outer radii of the grid to coincide with the extent of the torus, i.e. from \f$2.4\times
10^{-2}\f$ to \f$4.8\times 10^{-2}\f$ pc.

\subsection TutorialReverberationDis Time-lag and energy distribution

The following python script visualizes the time-lag and energy distribution stored by SKIRT as a spectral-time map
(STM) in FITS format.

\code{.py}
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LogNorm
from astropy.io import fits

def process_and_plot(path_stm, path_gas):
    e_edges = np.logspace(np.log10(2.0), np.log10(12.0), 1001)
    e_centers = np.sqrt(e_edges[:-1] * e_edges[1:])
    e_widths = np.diff(e_edges)

    t_edges = np.linspace(0, 3.08567758e18 / 2.99792458e10, 1001)
    t_widths = np.diff(t_edges)
    t_edges_shifted = t_edges - t_widths[0] / 2.0
    t_scaled = (t_edges_shifted[:-1] + t_edges_shifted[1:]) / 2.0 / 1e6

    with fits.open(path_stm) as h_stm, fits.open(path_gas) as h_gas:
        data_stm = h_stm[0].data.astype(float)
        data_rho = np.squeeze(h_gas[0].data).astype(float)

    data_stm[data_stm <= 1e-50] = np.nan
    data_rho[data_rho <= 1e-50] = np.nan

    spectrum = np.nansum(data_stm * t_widths[:, None], axis=0)
    lightcurve = np.nansum(data_stm * e_widths[None, :], axis=1)

    fig, axs = plt.subplots(2, 2, figsize=(12, 10), gridspec_kw={'wspace': 0.3, 'hspace': 0.3})
    ax_top, ax_density, ax_main, ax_right = axs.flatten()

    for cmap in ['viridis', 'magma']:
        plt.get_cmap(cmap).set_bad('white')

    # (a) Spectrum
    ax_top.plot(e_centers, spectrum, color='black', lw=1.5)
    ax_top.set(xscale='log', yscale='log', xlim=(2, 12), xlabel='Energy (keV)', ylabel='Flux')

    # (b) Density Map
    extent = np.array([-512.5, 511.5, -512.5, 511.5]) * 9.346484375e-5 * 100
    im = ax_density.imshow(data_rho, origin='lower', cmap='magma', extent=extent, norm=LogNorm())
    ax_density.set(xlabel=r'X ($10^{-2}$ pc)', ylabel=r'Y ($10^{-2}$ pc)', xlim=(-5, 5), ylim=(-5, 5))
    plt.colorbar(im, ax=ax_density, label='Number density')

    # (c) STM
    X, Y = np.meshgrid(e_edges, t_edges_shifted / 1e6)
    pcm = ax_main.pcolormesh(X, Y, data_stm, cmap='viridis', norm=LogNorm())
    ax_main.set(xscale='log', xlim=(2, 12), ylim=(-0.2, 40), xlabel='Energy (keV)', ylabel='Time lag ($10^6$ s)')
    plt.colorbar(pcm, ax=ax_main, label='Flux Density')

    # (d) Lightcurve
    ax_right.plot(lightcurve, t_scaled, color='black', lw=1.5)
    ax_right.set(xscale='log', xlim=(1e-18, 1e-7), ylim=(-0.2, 40), xlabel='Flux', ylabel='Time lag ($10^6$ s)')

    plt.savefig('stm.png', dpi=300, bbox_inches='tight')
    plt.close()

if __name__ == "__main__":
    base = "reverberation"
    process_and_plot(base + "_timelagenergy_stm_total.fits", base + "_density_gas_g_xy.fits")
\endcode

\image html TutorialReverberationResults.png

The script generates the figure displayed above, including the following four panels:
- top-right: a 2D density cut through the medium along the equatorial plane
- bottom-left: the spatially integrated Spectral Time Map (Time lag vs. Energy, colored by Flux)
- top-left: the STM integrated over Time Lag, i.e. the spectrum (Flux vs. Energy)
- bottom-right: the STM integrated over Energy (viewed sideways), i.e. the light curve (Flux vs. Time lag)

Direct emission from the source is shown at a time lag of \f$0\f$, whereas reprocessed emission is shown at time lags
\f$>0\f$. The prominent features among the reprocessed emission are fluorescence lines, such as the
\f$\mathrm{Fe}\;\mathrm{K}\alpha\f$ line at \f$6.4~\mathrm{keV}\f$. Because the photoelectric absorption cross-section
is higher at lower energies, high-energy photons can penetrate and reach the outer regions of the torus. Consequently,
these fluorescence lines are produced by the high-energy photons in these outer regions. As a result, the emission of
these lines is delayed, exhibiting relatively large time-lag values compared to those of the low-energy reprocessed
continuum emission, which is produced predominantly in the inner regions.

\subsection TutorialReverberationMap Reverberation mapping

The time lag of the \f$\mathrm{Fe}\;\mathrm{K}\alpha\f$ line band relative to the continuum band of the direct
emission, measured using the cross-correlation function (CCF), enables reverberation mapping of the surrounding
material. First, an intrinsic light curve is assumed. Second, this intrinsic light curve is convolved with the
two-dimensional time-lag and energy distribution obtained by SKIRT to produce a mock observed light curve. Third, the
mock data are integrated over the fluorescence line energy band and the continuum energy band. Finally, by calculating
the CCF between the mock observed light curves of the fluorescence line and the continuum, we obtain a correlation
profile that can be directly compared with observations.
